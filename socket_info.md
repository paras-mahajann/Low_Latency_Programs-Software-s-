# server functions


1.initialize and create socket
2.bind the socket with ip and port
3.listen on the socket
4.Accept the connection - accept(),connect()
5.send and receive the data - recv(),send(),recvfrom(),sendto()
6.Disconnect the socket - close(socket);


# client functions

1.Initialize and create sokcet - socket();
2.connect to the server - connect().
3.send and receive data - recv(),send(),recvfrom(),sendto()
4.Disconnect - close(socket);
